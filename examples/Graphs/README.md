# Graphs

Graph visualizations: animated tree/bubble chart, 10x10 lattice, and a Markov chain weather model.

## Archetypes

- `GraphNodes` with labels, colors, radii, and positions
- `GraphEdges` with directed graph type
- `TextDocument` (markdown description)

## Run

```bash
dotnet run --project examples/Graphs
dotnet run --project examples/Graphs -- --spawn   # opens Rerun viewer
```
