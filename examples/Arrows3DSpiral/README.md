# Arrows3DSpiral

100 colored 3D arrows arranged in a spiral pattern with logarithmic lengths.

## Archetypes

- `Arrows3D` with `Vector3D`, `Position3D`, `Color`

## Run

```bash
dotnet run --project examples/Arrows3DSpiral
dotnet run --project examples/Arrows3DSpiral -- --spawn   # opens Rerun viewer
```
