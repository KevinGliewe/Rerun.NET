# ClearDemo

Log 4 colored arrows then clear them one by one, demonstrating the Clear archetype.

## Archetypes

- `Arrows3D` with `Vector3D`, `Position3D`, `Color`
- `Clear`

## Run

```bash
dotnet run --project examples/ClearDemo
dotnet run --project examples/ClearDemo -- --spawn   # opens Rerun viewer
```
