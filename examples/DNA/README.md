# DNA

Double helix DNA visualization with two color spirals, scaffolding lines, and animated bouncing beads.

## Archetypes

- `Points3D` (DNA strands and animated beads)
- `LineStrips3D` (scaffolding connecting strands)
- `Transform3D` (rotating the structure)

## Run

```bash
dotnet run --project examples/DNA
dotnet run --project examples/DNA -- --spawn   # opens Rerun viewer
```
