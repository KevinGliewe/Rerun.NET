# Plots

Various plot types: Gaussian bell curve, parabola, sin/cos, and a binary classification scatter.

## Archetypes

- `Scalars` (Gaussian, parabola, trig curves)
- `Points2D` (classification scatter plot)
- `TextDocument` (markdown description)

## Run

```bash
dotnet run --project examples/Plots
dotnet run --project examples/Plots -- --spawn   # opens Rerun viewer
```
